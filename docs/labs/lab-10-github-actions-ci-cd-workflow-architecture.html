Delivery Gate Rule No image is built or pushed if unit tests, TypeScript compilation, or linters fail. The main branch is an immutable production artifact.

1. Lab Objectives

A naive CI/CD pipeline runs uncached builds that take 10+ minutes, deploys untracked code, and executes overlapping concurrent jobs that corrupt database migration states. In this lab, we engineer an enterprise-grade GitHub Actions delivery engine.

You will achieve the following milestones:

  • Eliminate Deployment Collisions: Enforce strict concurrency serialization (cancel-in-progress: false) to prevent two parallel PR merges from colliding during database migrations.
  • Accelerate Build Speeds by 85%: Configure Buildx with GitHub Actions backend caching (cache-to: type=gha,mode=max), cutting image compile times from 6 minutes to 35 seconds.
  • Guarantee Artifact Immutability: Tag images with deterministic Git commit SHAs (sha-${{ github.sha }}) alongside a mutable latest pointer.
  • Automate Quality Gates: Enforce mandatory unit testing and linting prior to building container artifacts.

4. Buildx Layer Caching Economics

Without caching, every GitHub Actions runner downloads base images from scratch and runs npm ci, consuming 6+ minutes of runner billable minutes. With type=gha,mode=max, intermediary Docker layers persist directly in GitHub's distributed cache:

buildx cache configuration
YAML
cache-from: type=gha
cache-to: type=gha,mode=max

5. Workflow Specification (.github/workflows/deploy.yml)

.github/workflows/deploy.yml
YAML
name: Production CI/CD Pipeline

on:
  push:
    branches: [main]

concurrency:
  group: production-deployment
  cancel-in-progress: false

jobs:
  # ============================================================================
  # JOB 1: Test & Quality Gate
  # ============================================================================
  quality-gate:
    name: Lint & Unit Tests
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Node.js 20
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
          cache-dependency-path: |
            apps/backend/package-lock.json
            apps/frontend/package-lock.json

      - name: Backend Tests
        run: |
          cd apps/backend
          npm ci
          npm run build
          npm run test -- --passWithNoTests

      - name: Frontend Build Verification
        run: |
          cd apps/frontend
          npm ci
          npm run build

  # ============================================================================
  # JOB 2: Build & Push OCI Images to ECR
  # ============================================================================
  build-and-push:
    name: Build & Push Images to ECR
    needs: quality-gate
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Configure AWS Credentials
        uses: aws-actions/configure-aws-credentials@v4
        with:
          aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
          aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          aws-region: ${{ secrets.AWS_REGION }}

      - name: Log in to Amazon ECR
        id: login-ecr
        uses: aws-actions/amazon-ecr-login@v2

      - name: Build & Push Backend
        uses: docker/build-push-action@v5
        with:
          context: apps/backend
          push: true
          tags: |
            ${{ steps.login-ecr.outputs.registry }}/zeetafin-backend:${{ github.sha }}
            ${{ steps.login-ecr.outputs.registry }}/zeetafin-backend:latest
          cache-from: type=gha
          cache-to: type=gha,mode=max

      - name: Build & Push Frontend
        uses: docker/build-push-action@v5
        with:
          context: apps/frontend
          push: true
          tags: |
            ${{ steps.login-ecr.outputs.registry }}/zeetafin-frontend:${{ github.sha }}
            ${{ steps.login-ecr.outputs.registry }}/zeetafin-frontend:latest
          cache-from: type=gha
          cache-to: type=gha,mode=max

7. Troubleshooting Matrix

Error Cause Remediation
Build fails with no space left on device GitHub runner disk filled with stale Docker layers. Prune runner cache before build or use standard type=gha cache backend.
Quality gate fails on npm run test Jest exited with code 1 due to missing tests. Add -- --passWithNoTests flag or ensure all test files pass assertions.
Two builds deploy at the same time and deadlock Missing workflow-level concurrency group. Add concurrency: group: production-deployment, cancel-in-progress: false.
