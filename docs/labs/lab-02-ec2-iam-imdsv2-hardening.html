1. Lab Objectives

Provisioning a bare virtual machine is trivial. Engineering a resilient compute host with anti-SSRF defenses, automated keypair management, encrypted block storage, and dynamic inventory export requires staff-level rigor.

In this lab, you will achieve the following milestones:

  • Eliminate Hardcoded OS Credentials: Attach an IAM Instance Profile so the EC2 instance interacts with AWS APIs (such as Amazon ECR) using short-lived STS tokens.
  • Defeat Cloud SSRF Attacks with IMDSv2: Enforce session-token headers (http_tokens = "required") and lock network traversal to the host (http_put_response_hop_limit = 1).
  • Optimize Block Storage Performance & Cost: Configure an encrypted 20 GB gp3 root volume delivering baseline 3,000 IOPS and 125 MB/s throughput at 20% lower cost than gp2.
  • Bridge IaC into Configuration Management: Automate the creation of infra/ansible/inventory/hosts.ini using Terraform's local_file resource.

3. SSH Keypair Generation

Never generate production keys in the AWS console. Generate a local 4096-bit RSA or Ed25519 keypair and set strict POSIX file permissions:

terminal — local ssh key generation
BASH
# 1. Generate dedicated 4096-bit RSA keypair
ssh-keygen -t rsa -b 4096 -f ~/.ssh/zeetafin-key -C "admin@zeetafin"

# 2. Restrict private key permissions strictly to owner (0400)
chmod 400 ~/.ssh/zeetafin-key

# 3. Verify public key existence
ls -la ~/.ssh/zeetafin-key.pub

4. Dynamic Ubuntu 24.04 LTS Resolution

Hardcoding AMI IDs introduces cross-region failures. We use an AWS AMI data filter querying Canonical's official AWS account (099720109477):

infra/terraform/data.tf
HCL
data "aws_ami" "ubuntu" {
  most_recent = true
  owners      = ["099720109477"] # Canonical Official Account ID

  filter {
    name   = "name"
    values = ["ubuntu/images/hvm-ssd-gp3/ubuntu-noble-24.04-amd64-server-*"]
  }

  filter {
    name   = "virtualization-type"
    values = ["hvm"]
  }
}

5. EC2 & IAM Implementation

infra/terraform/compute.tf
HCL
# 1. AWS Key Pair
resource "aws_key_pair" "main" {
  key_name   = "zeetafin-production-key"
  public_key = file("~/.ssh/zeetafin-key.pub")
}

# 2. IAM Role for EC2
resource "aws_iam_role" "ec2_role" {
  name = "zeetafin-ec2-role-production"

  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Action    = "sts:AssumeRole"
      Effect    = "Allow"
      Principal = { Service = "ec2.amazonaws.com" }
    }]
  })
}

# 3. Attach ECR Read-Only policy to allow container pulls
resource "aws_iam_role_policy_attachment" "ecr_read" {
  role       = aws_iam_role.ec2_role.name
  policy_arn = "arn:aws:iam::aws:policy/AmazonEC2ContainerRegistryReadOnly"
}

# 4. IAM Instance Profile
resource "aws_iam_instance_profile" "ec2_profile" {
  name = "zeetafin-ec2-profile-production"
  role = aws_iam_role.ec2_role.name
}

# 5. Production Hardened EC2 Compute Instance
resource "aws_instance" "app_server" {
  ami                  = data.aws_ami.ubuntu.id
  instance_type        = "t3.medium"
  subnet_id            = aws_subnet.public.id
  vpc_security_group_ids = [aws_security_group.app_sg.id]
  key_name             = aws_key_pair.main.key_name
  iam_instance_profile = aws_iam_instance_profile.ec2_profile.name

  # Encrypted gp3 Root Storage Block
  root_block_device {
    volume_size           = 20
    volume_type           = "gp3"
    iops                  = 3000
    throughput            = 125
    encrypted             = true
    delete_on_termination = true

    tags = {
      Name = "zeetafin-root-volume-production"
    }
  }

  # Strict IMDSv2 Hardening (Anti-SSRF Protection)
  metadata_options {
    http_endpoint               = "enabled"
    http_tokens                 = "required" # Forces session-oriented PUT tokens
    http_put_response_hop_limit = 1          # Prevents container bridge egress
    instance_metadata_tags      = "enabled"
  }

  tags = {
    Name = "zeetafin-host-production"
  }
}

6. Dynamic Ansible Inventory Generation

Eliminate manual copy-pasting of IP addresses by rendering the Ansible inventory directly upon terraform apply:

infra/terraform/inventory.tf
HCL
resource "local_file" "ansible_inventory" {
  content = templatefile("${path.module}/templates/hosts.tpl", {
    public_ip = aws_instance.app_server.public_ip
  })
  filename        = "${path.module}/../ansible/inventory/hosts.ini"
  file_permission = "0644"
}
infra/terraform/templates/hosts.tpl
INI
[app_servers]
zeetafin_host ansible_host=${public_ip} ansible_user=ubuntu ansible_ssh_private_key_file=~/.ssh/zeetafin-key

8. Verification & SSRF Test

terminal — host ssh & imdsv2 validation
BASH
# 1. Establish SSH connection using your private key
ssh -i ~/.ssh/zeetafin-key ubuntu@$(terraform output -raw ec2_public_ip)

# 2. Attempt legacy IMDSv1 query (Must fail with 401 Unauthorized)
curl -I http://169.254.169.254/latest/meta-data/
# Output: HTTP/1.1 401 Unauthorized

# 3. Issue legitimate IMDSv2 PUT request to acquire session token
TOKEN=$(curl -s -X PUT "http://169.254.169.254/latest/api/token" \
  -H "X-aws-ec2-metadata-token-ttl-seconds: 21600")

# 4. Query IAM security credentials using token
curl -s -H "X-aws-ec2-metadata-token: $TOKEN" \
  http://169.254.169.254/latest/meta-data/iam/security-credentials/
# Output: zeetafin-ec2-role-production

9. Troubleshooting Matrix

Issue Root Cause Remediation
Permission denied (publickey) Local key permissions too open or public key mismatch. Execute chmod 400 ~/.ssh/zeetafin-key. Confirm public_key = file("~/.ssh/zeetafin-key.pub") matches the local private key.
Container cannot fetch AWS credentials http_put_response_hop_limit = 1 prevents Docker bridge traversal. Expected behavior! Containers should never query host IMDS. Use IAM roles for tasks or inject scoped credentials.
Ansible inventory file not created Missing local_file resource declaration in Terraform. Check that local_file.ansible_inventory exists and directory infra/ansible/inventory/ is writable.
EBS volume unencrypted Missing encrypted = true block in root_block_device. Set encrypted = true in root_block_device and apply changes.

10. Hardening Checklist

  • [x] Dynamic Canonical Ubuntu 24.04 LTS AMI queried without hardcoded IDs.
  • [x] Ed25519 / RSA-4096 keypair generated locally; permissions locked to 0400.
  • [x] IAM Instance Profile assigned; zero hardcoded AWS secret keys on the VM.
  • [x] IMDSv2 mandatory (http_tokens = "required").
  • [x] Hop-limit locked to 1 (http_put_response_hop_limit = 1) to prevent container SSRF.
  • [x] Root volume encrypted with AWS KMS using high-performance gp3.
  • [x] Dynamic Ansible inventory automatically generated via local_file.
