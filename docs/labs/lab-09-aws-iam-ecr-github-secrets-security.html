1. Lab Objectives

Container delivery pipelines frequently collapse under the weight of excessive AWS permissions or run up thousands of dollars in storage fees by retaining stale dangling image layers. In this lab, we engineer private ECR infrastructure and least-privilege IAM bot identities.

You will achieve the following milestones:

  • Provision Private ECR Registries: Create private AWS repositories for zeetafin-backend and zeetafin-frontend with automated vulnerability scanning on push.
  • Slashing Registry Storage Burn by 80%: Configure ECR lifecycle policies that prune untagged images older than 14 days and limit tagged image retention to the 30 most recent releases.
  • Construct Least-Privilege IAM Policy: Author a tight IAM policy granting only image upload/download actions strictly bounded to the repository ARNs.
  • Hardening Repository Secrets: Establish GitHub Secret hygiene preventing credential leaks in CI/CD terminal outputs or container layer histories.

2. CI/CD Supply Chain Threat Model

The Risk of Over-Privileged CI Bots

If an attacker compromises a third-party GitHub Action or developer token, an over-privileged AWS credential could allow them to alter VPC security groups, spawn expensive EC2 crypto-miners, or exfiltrate database backups. Restricting the bot strictly to ECR actions isolates any blast radius.

# ECR Repository: NestJS Backend
resource "aws_ecr_repository" "backend" {
  name                 = "zeetafin-backend"
  image_tag_mutability = "MUTABLE" # Allows 'latest' tag repointing while using SHA tags

  image_scanning_configuration {
    scan_on_push = true
  }

  tags = {
    Name = "zeetafin-backend-ecr"
  }
}

    scan_on_push = true
  }

  }
}

4. ECR Cost-Optimization Lifecycle Policy

infra/terraform/ecr_lifecycle.tf
HCL
resource "aws_ecr_lifecycle_policy" "backend_policy" {
  repository = aws_ecr_repository.backend.name

  policy = jsonencode({
    rules = [
      {
        rulePriority = 1
        description  = "Expire untagged dangling build images after 14 days"
        selection    = {
          tagStatus   = "untagged"
          countType   = "sinceImagePushed"
          countUnit   = "days"
          countNumber = 14
        }
        action = { type = "expire" }
      },
      {
        rulePriority = 2
        description  = "Retain maximum 30 tagged production images"
        selection    = {
          tagStatus     = "tagged"
          tagPrefixList = ["sha-", "v"]
          countType     = "imageCountMoreThan"
          countNumber   = 30
        }
        action = { type = "expire" }
      }
    ]
  })
}

5. Least-Privilege IAM Robot

infra/terraform/iam_ci.tf
HCL
# IAM User for GitHub Actions CI/CD
resource "aws_iam_user" "ci_bot" {
  name = "zeetafin-github-actions-deployer"
  tags = { Purpose = "CI/CD Deployment Robot" }
}

# Policy granting ONLY ECR access
resource "aws_iam_policy" "ci_ecr_policy" {
  name        = "zeetafin-ci-ecr-push-policy"
  description = "Allows CI runner to authenticate and push to ZeetaFin ECR repos"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Sid      = "ECRAuthToken"
        Effect   = "Allow"
        Action   = ["ecr:GetAuthorizationToken"]
        Resource = "*"
      },
      {
        Sid    = "ECRPushPullSpecificRepos"
        Effect = "Allow"
        Action = [
          "ecr:BatchCheckLayerAvailability",
          "ecr:GetDownloadUrlForLayer",
          "ecr:GetRepositoryPolicy",
          "ecr:DescribeRepositories",
          "ecr:ListImages",
          "ecr:DescribeImages",
          "ecr:BatchGetImage",
          "ecr:InitiateLayerUpload",
          "ecr:UploadLayerPart",
          "ecr:CompleteLayerUpload",
          "ecr:PutImage"
        ]
        Resource = [
          aws_ecr_repository.backend.arn,
          aws_ecr_repository.frontend.arn
        ]
      }
    ]
  })
}

resource "aws_iam_user_policy_attachment" "ci_attach" {
  user       = aws_iam_user.ci_bot.name
  policy_arn = aws_iam_policy.ci_ecr_policy.arn
}

6. GitHub Secrets Hygiene

Configure the following secrets in GitHub Repository Settings → Secrets and variables → Actions:

Secret Name Source Value Purpose
AWS_ACCESS_KEY_ID Access Key generated for zeetafin-github-actions-deployer AWS ECR authentication
AWS_SECRET_ACCESS_KEY Secret Key generated for zeetafin-github-actions-deployer AWS ECR authentication
AWS_REGION us-east-1 Target AWS Region
AWS_ACCOUNT_ID 12-digit AWS Account ID ECR registry URL resolution
EC2_HOST Public IP from terraform output ec2_public_ip Remote SSH host target
EC2_SSH_KEY Raw private key from ~/.ssh/zeetafin-key Zero-agent deployment authentication
DB_PASSWORD High-entropy alphanumeric string (32+ chars) Production PostgreSQL master password
JWT_SECRET Cryptographic random string (64+ chars) HMAC-SHA256 token signing

8. Troubleshooting Matrix

Error Root Cause Solution
denied: Your authorization token has expired ECR login tokens are strictly valid for 12 hours. Re-run aws ecr get-login-password to fetch fresh session token.
User ... is not authorized to perform: ecr:PutImage IAM policy resource ARN does not match repository name. Verify Resource array in IAM policy includes repository ARN.
High monthly AWS bills for container storage Missing lifecycle rules; thousands of untagged CI build layers retained. Attach aws_ecr_lifecycle_policy with 14-day untagged expiration rule.
