Configuration Rule Never SSH into a server to run ad-hoc apt commands. If it's not codified in an idempotent playbook, it does not exist in production.

1. Lab Objectives

If your server setup relies on manual SSH sessions and copy-pasted curl | bash scripts, you have replaced cloud infrastructure drift with operating system configuration drift. In this lab, we automate host provisioning using Ansible.

You will complete the following production engineering milestones:

  • Defeat Cloud-Init Lock Contention: Automatically wait for Ubuntu background upgrades (/var/lib/dpkg/lock-frontend) to release before initiating package installations.
  • Secure Upstream Package Repositories: Install the official Docker GPG signing key to /etc/apt/keyrings/docker.gpg with signed-by verification.
  • Deploy Modern Container Tooling: Install docker-ce, docker-ce-cli, containerd.io, docker-buildx-plugin, and the native docker-compose-plugin.
  • Enforce Least-Privilege Execution: Grant the unprivileged ubuntu user membership in the docker group, eliminating the need to execute container commands with sudo.

2. Terraform vs. Ansible Architectural Boundary

Responsibility Dimension Terraform (Day 0 - IaC) Ansible (Day 1 - Config Management)
Scope Cloud Perimeter (VPC, Subnet, Route, EC2, IAM) Inside OS (APT Packages, Systemd, Daemons, Users)
Execution Paradigm Declarative State Engine (via AWS Cloud APIs) Idempotent Task Execution (via SSH Protocol)
State Tracking terraform.tfstate (JSON file in S3/Local) Stateless; queries live OS facts (setup module)
Drift Remediation Recreates or modifies cloud resource attributes Re-converges host to desired target state without reboot

5. Docker Playbook Implementation

infra/ansible/playbook.yml
YAML
---
- name: Configure Production Docker CE Host
  hosts: app_servers
  become: true
  vars:
    docker_packages:
      - docker-ce
      - docker-ce-cli
      - containerd.io
      - docker-buildx-plugin
      - docker-compose-plugin

  tasks:
    # 1. Defeat dpkg lock race conditions from cloud-init
    - name: Wait for automatic system updates (dpkg lock) to release
      ansible.builtin.raw: |
        while fuser /var/lib/dpkg/lock-frontend >/dev/null 2>&1; do
          sleep 3
        done
      changed_when: false

    # 2. Install essential system dependencies
    - name: Install APT prerequisite utilities
      ansible.builtin.apt:
        name:
          - ca-certificates
          - curl
          - gnupg
          - lsb-release
        state: present
        update_cache: true

    # 3. Create secure keyrings directory
    - name: Ensure /etc/apt/keyrings directory exists
      ansible.builtin.file:
        path: /etc/apt/keyrings
        state: directory
        mode: '0755'

    # 4. Download and dearmor official Docker GPG key
    - name: Download official Docker GPG signing key
      ansible.builtin.get_url:
        url: https://download.docker.com/linux/ubuntu/gpg
        dest: /tmp/docker.gpg.raw
        mode: '0644'

    - name: Dearmor Docker GPG key to /etc/apt/keyrings/docker.gpg
      ansible.builtin.command:
        cmd: gpg --dearmor -o /etc/apt/keyrings/docker.gpg /tmp/docker.gpg.raw
        creates: /etc/apt/keyrings/docker.gpg

    - name: Clean up temporary raw GPG key
      ansible.builtin.file:
        path: /tmp/docker.gpg.raw
        state: absent

    # 5. Add Docker repository with signed-by specification
    - name: Add official Docker CE APT repository
      ansible.builtin.apt_repository:
        repo: >-
          deb [arch={{ 'amd64' if ansible_architecture == 'x86_64' else 'arm64' }}
          signed-by=/etc/apt/keyrings/docker.gpg]
          https://download.docker.com/linux/ubuntu
          {{ ansible_distribution_release }} stable
        state: present
        filename: docker

    # 6. Install Docker CE Engine and Compose plugin
    - name: Install Docker CE packages
      ansible.builtin.apt:
        name: "{{ docker_packages }}"
        state: present
        update_cache: true

    # 7. Enable and start docker daemon
    - name: Ensure Docker systemd service is active and enabled
      ansible.builtin.systemd:
        name: docker
        state: started
        enabled: true

    # 8. Add unprivileged ubuntu user to docker group
    - name: Add user ubuntu to docker group
      ansible.builtin.user:
        name: ubuntu
        groups: docker
        append: true

8. Production Troubleshooting Matrix

Error Root Cause Fix
Could not get lock /var/lib/dpkg/lock-frontend Ubuntu unattended-upgrades active in the background. Use the ansible.builtin.raw wait loop shown in Task 1 before calling apt.
permission denied while trying to connect to the Docker daemon socket User added to docker group but session has not refreshed. Execute newgrp docker in current session or reconnect via SSH.
GPG error: ... Key is stored in legacy trusted.gpg Outdated apt-key add method used. Dearmor key directly to /etc/apt/keyrings/docker.gpg with signed-by attribute.
docker-compose: command not found Legacy Python pip compose expected instead of Compose v2. Use docker compose (v2 subcommand plugin), not docker-compose.
